Create a Python script for realistic meta-feature engineering from PUMS census data to predict Medicaid-only insurance status.

**File**: `03_fe_realistic.py`

**Purpose**: Create ~25-35 highly interpretable, actionable features combining multiple raw features into composite scores and indicators

**Requirements**:

1. **Load and Prepare Data**:
   - Load `data/processed/psam_p38_cleaned.csv`
   - Filter to ages 18-65: `AGEP >= 18` and `AGEP <= 65`
   - Create target variable: `medicaid_only = (HINS4 == 1) & (PRIVCOV == 2)` as binary (0/1)
   - Print target distribution and class imbalance ratio
   - Drop unnecessary columns: `PWGTP1-PWGTP80`, F* flags, IDs, insurance columns (HINS1-7, PUBCOV, PRIVCOV, HICOV), `NAICSP`, `SOCP`

2. **Identify and Preprocess Categorical Variables**:
   
   **Step 1: Identify Raw Categoricals**
   - Before engineering meta-features, identify all categorical variables in raw data
   - Use dtype detection + unique value analysis
   - Common categoricals needed for meta-features: `SEX`, `MAR`, `ESR`, `COW`, `SCHL`, `SCH`, `OCCP`, `INDP`, `RELSHIPP`, `MIG`, `STATE`, `PUMA`, `REGION`, `CIT`, `NATIVITY`, `RAC1P`, `HISP`, `DIS`, disability flags (`DDRS`, `DEAR`, `DEYE`, `DOUT`, `DPHY`, `DREM`), `LANX`, `MIL`, `WKL`, `WRK`, `DIVISION`, `QTRBIR`, etc.
   
   **Step 2: Group High-Cardinality Features**
   - **`OCCP`**: Convert to string, zero-pad to 4 digits (20 → '0020'), extract first 2 → `OCCP_2digit`
     - Example: OCCP=20 → '0020' → '00', OCCP=4720 → '4720' → '47'
   - **`INDP`**: Convert to string, zero-pad to 4 digits (170 → '0170'), extract first 2 → `INDP_2digit`
     - Example: INDP=170 → '0170' → '01', INDP=6991 → '6991' → '69'
   - Drop original `OCCP` and `INDP`
   
   **Step 3: Handle Missing Values**
   - Numeric: fill with median
   - Categorical: fill with 'Missing' category (preserves signal of missingness)
   - Document missing value patterns

3. **Business Feature Groups** (select and engineer):

   **GROUP 1: Income & Affordability (4 features)**
   - Raw features: none
   - Engineer:
     - `income_group`: categorize WAGP in 5 groups
     - `poverty_band`: Categorize POVPIP into '<100%', '100-138%', '138-200%', '200-400%', '>400%'
     - `has_wage_income`: Binary (WAGP > 0)
     - `has_self_employment`: Binary (SEMP > 0)

   **GROUP 2: Employment Quality (2 features)**
   - Raw features: none
   - Engineer:
     - `employment_status_simple`: Recode ESR to 'Employed', 'Unemployed', 'Not_in_labor_force'
     - `employer_type`: Simplify COW to 'Private', 'Government', 'Self_employed', 'Unpaid'

   **GROUP 3: Demographics & Life Stage (5 features)**
   - Raw features: `AGEP`, `SEX`, `MAR`
   - Engineer:
     - `age_group`: Cut into '18-25', '26-35', '36-45', '46-55', '56-65'
     - `marital_status_simple`: Recode MAR to 'Married', 'Divorced_Separated', 'Widowed', 'Never_married'

   **GROUP 4: Education (2 features)**
   - Raw features: none
   - Engineer:
     - `education_level`: Recode SCHL to 'Less_than_HS', 'HS_diploma', 'Some_college', 'Bachelors', 'Graduate'
     - `currently_enrolled`: Binary (SCH in [2, 3])

   **GROUP 5: Health & Disability (0 features)**
   - Raw features: none
   - Engineer:
     - none

   **GROUP 6: Geography (4 features)**
   - Raw features: `STATE`, `PUMA`, `REGION`, `DIVISION`
   - Keep as-is (categorical)

4. **Feature Selection Logic**:
   - Total target: ~17 features (including engineered)
   - Document rationale for each feature/group in code comments
   - Calculate correlation with target for each group

5. **Save Outputs**:
   - **Categorical version**: `feature_engineering/output/03_fe_realistic_categorical.csv` (~50-70 columns)
   - **Encoded version**: 
     - Identify all categorical columns in final realistic feature set
     - Create dummy variables: `pd.get_dummies(df, columns=categorical_cols, drop_first=True)`
     - Save as `feature_engineering/output/03_fe_realistic_encoded.csv`
     - Print: "Categorical features: [list], Dummy columns created: [N]"
   - **Realisitc report**: Save to `feature_engineering/output/03_fe_realistic_report.txt` with:
     - Feature count by group
     - Engineered feature definitions
     - Rationale for each group
     - Correlation with target by feature and by group
     - Marketing use cases for each feature group
   - **Feature metadata CSV**: Feature name, group, data type, engineering method to `feature_engineering/output/03_fe_realistic_metadata.csv`

6. **Visualizations**:
   - Feature importance (correlation with target) bar chart
   - Distribution of composite scores (affordability, employment quality, health risk, insurance readiness)
   - Target rate by key categorical features (life stage, job stability, poverty level)
   - Correlation matrix of all meta-features
   - Save to `feature_engineering/output/` with prefix `03_fe_` as PNG with 300 DPI
