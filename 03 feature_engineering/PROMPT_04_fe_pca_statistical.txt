Create a Python script to apply PCA dimensionality reduction to statistically-selected features from PUMS census data.

**File**: `04_fe_pca_statistical.py`

**Purpose**: Reduce dimensionality of statistically-selected features using Principal Component Analysis while retaining 95% of variance

**Requirements**:

1. **Load Data**:
   - Load `feature_engineering/output/01_fe_statistical_categorical.csv`
   - Separate target variable (`medicaid_only`) from features
   - Print: original dataset shape

2. **Preprocessing for PCA**:
   
   **Step 1: Load and Inspect Data Types**
   - Separate target from features
   - Use `df.dtypes` and `df.select_dtypes()` to identify feature types
   - Print: "Numeric features: [N], Categorical features: [M]"
   
   **Step 2: Identify ALL Categorical Features**
   - Explicitly check for: object dtype, category dtype, int64 with < 20 unique values
   - Common categoricals that must be encoded:
     - Binary: `SEX`, `DIS`, disability flags (DDRS, DEAR, DEYE, DOUT, DPHY, DREM), `LANX`, `MIL`, `NATIVITY`, `GCL`
     - Ordinal: `MAR`, `SCHL`, `ESR`, `COW`, `CIT`, `RELSHIPP`, `SCH`, `WKL`, `WRK`, `QTRBIR`, `RC`, `RACNUM`
     - Nominal: `STATE`, `REGION`, `DIVISION`, `PUMA`, `RAC1P`, `HISP`, `OCCP_2digit`, `INDP_2digit`, `RAC2P`, `RAC3P`, `ANC`, `ANC1P`, `ANC2P`, `MSP`, `RACAIAN`, `RACASN`, `RACBLK`, `RACNH`, `RACPI`, `RACWHT`, `RACSOR`
   - Print full list of identified categorical features
   
   **Step 3: Verify No Categoricals Missed**
   - Check: are there any non-numeric dtypes remaining after filtering?
   - Check: are there numeric columns with suspiciously few unique values?
   - If found, print warning: "Potential categorical variable missed: [name] with [n] unique values"
   
   **Step 4: Create Dummy Variables**
   - Apply `pd.get_dummies(df, columns=categorical_cols, drop_first=True)` to ALL identified categoricals
   - Track mapping: store a dictionary of {original_feature: [dummy_col1, dummy_col2, ...]}
   - For example: `MAR` → [`MAR_2`, `MAR_3`, `MAR_4`, `MAR_5`] (if 5 categories and drop_first=True)
   - Print: "Created [N] dummy columns from [M] categorical features"
   - Print: "Total features before encoding: [X], after encoding: [Y]"
   
   **Step 5: Verify All Numeric**
   - After dummy encoding, verify: `df.select_dtypes(include=[np.number]).shape[1] == df.shape[1]`
   - If not all numeric, raise error with details of non-numeric columns
   - Print: "Verification passed: all features are numeric"
   
   **Step 6: Handle Missing Values**
   - Check for any remaining NaN values
   - Impute with median (should be rare if preprocessing was done correctly)
   - Print: "Missing values after encoding: [count]"

3. **Standardization**:
   - Use `StandardScaler` from sklearn to standardize ALL features (mean=0, std=1)
   - Fit scaler on all data
   - Transform all features
   - Save fitted scaler to `feature_engineering/output/04_fe_pca_statistical_scaler.pkl`
   - Print: "Standardization complete"

4. **Apply PCA**:
   - Use `PCA(n_components=0.95)` to retain 95% of variance
   - Fit PCA on standardized features
   - Transform features to principal components
   - Print:
     - Number of components selected
     - Total variance explained (should be ~95%)
     - Variance explained by each of first 10 components
   - Save fitted PCA model to `feature_engineering/output/04_fe_pca_statistical_model.pkl`

5. **Component Analysis**:
   - Extract component loadings (PCA.components_)
   - For each of the first 10 components:
     - Identify top 10 features with highest absolute loadings
     - Map dummy variables back to original categorical features
     - Create interpretive label (e.g., "PC1_Income_Employment")
   - Calculate correlation between each PC and target
   - Save loadings to `feature_engineering/output/04_fe_pca_statistical_loadings.csv`

6. **Save Outputs**:
   - **PCA dataset**: DataFrame with target + PCA components, save to `feature_engineering/output/04_fe_pca_statistical.csv`
     - Columns: `medicaid_only`, `PC1`, `PC2`, ..., `PCN`
   - **Analysis report**: Save to `feature_engineering/output/04_fe_pca_statistical_report.txt`:
     - Original dimensions vs PCA dimensions
     - Total variance explained
     - Variance explained per component (first 20)
     - Top feature loadings for first 10 components
     - Correlation of each PC with target
     - Interpretation of top 5 components
   - **Variance explained CSV**: Component number, variance explained, cumulative variance to `feature_engineering/output/04_fe_pca_statistical_variance.csv`

7. **Visualizations**:
   - **Scree plot**: Variance explained by each component (first 30 components)
   - **Cumulative variance plot**: Cumulative variance explained
   - **Biplot**: PC1 vs PC2 with points colored by target (sample if > 5000 points)
   - **Loadings heatmap**: First 10 components vs top 30 features (by absolute loading)
   - **Correlation bar chart**: Correlation of each PC (first 20) with target
   - Save all to `feature_engineering/output/` with prefix `04_fe_pca_statistical_` as PNG with 300 DPI

8. **Comparison Section**:
   - Compare dimensions: original (~120-150) → PCA (~30-40)
   - Dimension reduction ratio
   - Information retention (95% variance)
   - Print summary comparison table
